MarketScope, portable
=====================

Start MarketScope.exe. Nothing needs to be installed and no administrator rights are needed.

MarketScope keeps its watchlist and temporary files in the "data" folder next to
MarketScope.exe, created on first start, so your watchlist travels with the stick. To start from
scratch, close MarketScope and delete the data folder.

It needs an internet connection: prices come from Binance (crypto) and Yahoo Finance (stocks and
forex; unofficial, for personal use), with the ECB's reference rates as a fallback for forex, and
headlines from public news feeds. It only reads public data; it never signs in anywhere and never
places orders.

If Windows refuses to start it ("Smart App Control blocked an app" or "Windows protected your PC"):
MarketScope is not code-signed. Choose "More info" > "Run anyway", or ask whoever manages the PC.
